Made-up data, drawn as the terminal would draw it: Berkeley Mono (when installed, or the .otf files dropped next to this page) and the catppuccin-mocha palette. Only a preview: the bars and buttons stand in for keys, and the tree guides are CSS borders because a browser does not draw box characters edge to edge. Tap a row with an arrow to fold it.
